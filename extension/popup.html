Start collaborating

  1. Connect Rub Minds MCP in ChatGPT or Claude first.
  2. Open an existing conversation with visible messages.
  3. Find the Rub Minds · Continuation panel on that page.
  4. Review its settings, then press Start yourself.

This first extension release does not configure MCP for you, run when the browser is closed, or start automatically. Keep the conversation tab open and monitor it.
